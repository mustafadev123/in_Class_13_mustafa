# Firebase Auth Lab

Flutter implementation for In-Class Activity 13. The app uses Firebase
Authentication for registration, sign-in, sign-out, profile access, and
password updates.

## Firebase setup

1. Create or open a Firebase project.
2. Enable **Authentication > Sign-in method > Email/Password**.
3. Install the FlutterFire CLI:

   ```powershell
   dart pub global activate flutterfire_cli
   ```

4. From this project directory, connect the app to your Firebase project:

   ```powershell
   flutterfire configure
   ```

   Select Android and web. This replaces the placeholder values in
   `lib/firebase_options.dart` with project-specific configuration.
5. Run the app:

   ```powershell
   flutter run
   ```

Do not commit passwords or private credentials. Firebase client configuration
is normally generated by `flutterfire configure`; Firebase security rules, not
client-side routing, protect Firestore data.

## Implemented behavior

- `AuthService` centralizes Firebase Auth operations.
- `authStateChanges()` selects the signed-in profile or signed-out auth form.
- Registration and sign-in validate email and password before async work.
- Loading indicators prevent duplicate submissions.
- Firebase errors are translated into useful user-facing messages.
- The protected profile displays the signed-in email.
- Password updates handle the recent-login requirement.
- Sign-out returns the app to the signed-out screen.
